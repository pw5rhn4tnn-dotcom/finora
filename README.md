# Finora

Finora — проект веб-приложения для управления личными финансами: учет доходов и расходов, месячное планирование и понятная картина финансового состояния.

**Статус: в разработке, Stage 0 — архитектура и документация.** Сейчас подготовлена документационная основа. Код приложения, база данных, Docker-конфигурация, API, UI и тесты еще не созданы. Описанные ниже возможности запланированы для v1.0.

## Планируемые возможности

- Регистрация и вход, независимые данные каждого пользователя, два demo-аккаунта.
- Транзакции и категории: CRUD, поиск, фильтры, сортировка, серверная пагинация, сохраненный курс валюты на момент операции.
- Месячные бюджеты с прогрессом и отображением превышения.
- Обзор финансов: показатели месяца, расходы по категориям, динамика за шесть месяцев, top-5 и детерминированные Financial Insights.
- Ежемесячные регулярные операции с восстановлением пропущенных запусков.
- CSV-мастер с сопоставлением колонок/категорий, validation и предупреждением дублей; экспорт всех отфильтрованных операций.
- Журнал изменений с понятным сравнением значений до/после.

Планируется полностью русскоязычный адаптивный интерфейс с завершенной светлой темой и доступными основными сценариями. Семейный demo-профиль — отдельный аккаунт, без совместного пространства. Внешние FX API и LLM не используются в принятой архитектуре.

## Планируемый стек

| Часть | Технологии |
| --- | --- |
| Репозиторий | Monorepo, pnpm workspaces, Git/GitHub |
| Frontend | React, TypeScript, Vite, React Router, TanStack Query, React Hook Form, Zod |
| Интерфейс | Tailwind CSS, shadcn/ui, Radix UI, Recharts, Lucide, Motion |
| Backend | Node.js, NestJS — модульный монолит, Prisma, PostgreSQL, JWT cookie, Argon2id, Nest scheduling |
| Контракты | REST, Swagger/OpenAPI, генерируемые frontend types/client |
| Проверки и запуск | Vitest, Testing Library, Playwright, Docker Compose, Nginx, GitHub Actions |

Версии и команды будут зафиксированы при реализации. Цель поставки — запуск UI, API и seeded PostgreSQL одной командой Docker Compose без дополнительной ручной настройки.
